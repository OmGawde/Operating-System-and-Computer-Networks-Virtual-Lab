Architecture Basics

The Client-Server architecture is the foundation of the modern web. The client (your browser) initiates a conversation by sending a Request to a specific port.

check_circle

Port 80 (HTTP)

Unencrypted, clear-text data transfer.

verified_user

Port 443 (HTTPS)

Encrypted communication using TLS/SSL.

Every response includes a Status Code (e.g., 200 OK, 404 Not Found) informing the client of the outcome.
