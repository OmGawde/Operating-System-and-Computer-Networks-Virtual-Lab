The 3-Way Handshake

  • 01.

    SYN: Client sends a synchronize sequence number packet to the server to initiate connection.

  • 02.

    SYN-ACK: Server acknowledges the request and sends its own sequence number back.

  • 03.

    ACK: Client sends final acknowledgement. Connection is now established.

window

Sliding Window Logic

Instead of waiting for an ACK for every single packet, TCP sends a "window" of packets. This maximizes throughput by utilizing bandwidth while waiting for confirmations.
