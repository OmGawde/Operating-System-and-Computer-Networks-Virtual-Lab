Routing Protocols

Explain the core difference between OSPF and BGP in terms of algorithm usage.

touch_app Tap to reveal answer
Correct Logic Card 12/48

OSPF (Open Shortest Path First) is an IGP that uses the Dijkstra SPF algorithm for intra-domain routing.

BGP (Border Gateway Protocol) is an EGP that uses a Path-Vector algorithm focused on policies and AS hops rather than simple cost metrics.

OSPF: Link-State
BGP: Path-Vector
