The ARP Phase

Before sending an ICMP packet, PC-A must resolve the MAC address of PC-B. It sends a Layer 2 Broadcast.

# arp -a
Target: 192.168.1.2
Broadcast: FF:FF:FF:FF:FF:FF

The ICMP Exchange

Once the MAC is known, the Echo Request is sent. PC-B responds with an Echo Reply to confirm connectivity.

# ping 192.168.1.2
Reply from 192.168.1.2: bytes=32 time=1ms TTL=64

Network Insights

Switches learn port locations via ARP traffic. If PC-B was on a different subnet, PC-A would target the Gateway's MAC instead.
